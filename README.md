# Telegram Group Reply Bot

Bu bot guruhdagi foydalanuvchi xabariga reply qilib:

"Lichkangizga maʼlumot yubordik ✅"

deb javob beradi. Foydalanuvchining lichkasiga hech narsa yubormaydi.

## Render sozlamalari

Build Command:
pip install -r requirements.txt

Start Command:
python bot.py

Environment Variables:
BOT_TOKEN = @BotFather bergan token
WEBHOOK_SECRET = istalgan uzun maxfiy matn

Render deploy qilingandan keyin botni guruhga admin qilib qoʻying va @BotFather orqali Group Privacy'ni o'chiring.
